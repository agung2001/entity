# Credits

Built with [Vue 3](https://vuejs.org), [Vite](https://vite.dev) and
[Electron](https://www.electronjs.org).

- **Interface** — the layout, the pixel marks and the small motion details are part
  of the app. The rules behind them are written down in
  [`DESIGN.md`](../DESIGN.md).
- **Sound** — the "Pixel Area 51" cue set is synthesized locally with Web Audio.
  There are no audio files in the repository and nothing is downloaded.
- **Fonts** — [Geist](https://vercel.com/font), bundled locally so the app renders
  the same offline.
- **Screenshots and demos** — captured from the app's own workspaces; the campaign,
  budget, itinerary and research examples are real threads, not mock-ups. How they are
  recorded and encoded: [README media](assets/README.md).

Third-party runtime dependencies are the ones listed in `package.json`; the release
build ships production modules only.
