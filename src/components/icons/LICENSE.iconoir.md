# iconoir — the four glyphs in this directory

`src/components/icons/UiIcon.vue` renders a small set of iconoir glyphs, copied
here rather than imported as a package: this app vendors its drawings (the
harness marks come from `thesvg.org` the same way) and four 24 × 24 files do not
justify the first runtime dependency added for markup alone.

Upstream: https://github.com/iconoir-icons/iconoir — MIT, reproduced below.

| file | stands for |
| --- | --- |
| `refresh.svg` | read the source again |
| `refresh-double.svg` | every machine, re-scanned together |
| `scanning.svg` | one host, read |
| `nav-arrow-right.svg` | open one machine's page |
| `trash.svg` | discard this copy's snapshot |
